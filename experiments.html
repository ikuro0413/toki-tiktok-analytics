TOKI検証パターン2026-07-31 設計

次に何を確かめるか
— 変数を1つずつ潰す5つの実験

30投稿の分析で「効いていそうだが分離できていない」変数が残った。勘で量産する前に、1回につき1つだけ動かして確かめる。どれも通常の投稿枠で回せるので、追加のコストはほぼ制作の組み替えだけになる。

実験の共通ルール

この5つを守らないと、何が効いたのか今回と同じように分からなくなる。

RULE 1
1回に動かす変数は1つだけ
8億円の3バージョンは、テイストと縦横と箱と時刻が同時に動いていた。結果的に縦横の差は取れたが、テイストの差は取れていない。
RULE 2
本文は完全に同一にする
内容の面白さは最大のノイズ。同じ本文を使い回せば内容を定数にできる。テイストや縦横の検証では必ず本文を固定する。
RULE 3
判定は投稿24時間後の再生数で行う
今日、takeの297億円は投稿1時間で208再生・いいね率2.40%だったが、3,785再生に伸びた時点で0.79%まで落ちた。分母が小さいうちの反応率は使えない。
RULE 4
2倍未満の差は「判定保留」にする
同じ型でも箱と日で再生が数倍ぶれる。縦横は6.5倍差だったので結論を出せたが、1.5倍程度なら偶然の範囲として扱い、もう1回まわす。
RULE 5
箱の地力差はクロスオーバーで打ち消す
A案をManuel・B案をintegratorで出したら、次は入れ替えて同じ比較をやる。2回とも同じ側が勝てば箱ではなく変数の効果と言える。

実験1 — bioに「フォローする理由」を書く

01 プロフィール文だけを変えて、フォロワー転換が動くか見る 最優先
なぜ最優先か
総再生100,929に対して、この4日で増えたフォロワーは6箱合計で13人程度。リンク解禁の条件がフォロワー数である以上、ここが全体のボトルネックになっている。しかも制作コストがゼロで、今日中に着手できて、投稿の実験と並行して回せる。
動かすもの
bioの文章
固定するもの
投稿内容投稿頻度箱
手順
育成中の4箱を2つに割る。介入群＝Manuel と 睡眠学のbioに「何を毎日投稿しているか」を一行で書く。たとえば「毎晩21時、眠りの話をひとつ。」のように、次の投稿を期待させる形にする。対照群＝integrator と あんなは現状のまま触らない。3日間そのまま投稿を続け、再生あたりのフォロワー増を比べる。
現状の値（起点）
箱群現フォロワーbio
Manuel介入12tiktokやめたい
睡眠学介入1未記入
integrator対照6tiktok見るのやめよ
あんな対照33未記入
判定：3日後に「増えたフォロワー ÷ その間の再生数」を群ごとに比較する。介入群が対照群の2倍以上なら、bioの文章が効くと判断して残り2箱にも展開する。差が出なければ、問題はbioではなくプロフィールに到達していないこと（＝スライド末尾のCTA）にあると分かるので、実験3へ進む。

実験2 — 縦書きは睡眠ネタでも効くか

02 勝ち筋の睡眠ノウハウを縦書き化して、横書き原版と比べる 最優先
何がまだ分かっていないか
縦書きが横書きの6.5倍を取ったのは事実だが、縦書き3本はすべて社会・時事の題材だった。1枚1メッセージでスワイプさせる形が、重い話題と相性が良いだけかもしれない。睡眠ノウハウでも同じ差が出るなら、縦書きを全面的に標準にしてよい。
動かすもの
縦書き / 横書き
固定するもの
本文古文書テイスト投稿時刻
素材
「10-3-2-1-0」を使う。保存率0.408%で30本中2位、いいね率1.97%も上位で、横書き版の実績（Manuel 2,942再生）が既にあるため比較の基準が取れている。本文を1枚1メッセージに割って28枚前後の縦書き版を作る。
組み方（クロスオーバー）
ラウンド素材縦書き版横書き版
1日目10-3-2-1-0integratorあんな
3日目寝る前NG5選あんなintegrator
判定：2ラウンドとも縦書き側が2倍以上勝てば、縦書きを全ジャンルの標準にする。時事だけで効いて睡眠では効かないなら、縦書きは題材を選ぶ形式だと分かるので、時事・論争系にだけ使う。なお同一素材を2箱に同時投下するのは重複判定のリスクがあるため、テイストを変えて別物にしておく。

実験3 — 育成中の箱のCTAをフォロー誘導に変える

03 飛び先のない診断CTAを、フォロー誘導に差し替える 高
何を確かめるか
睡眠シリーズの最終枚は「睡眠力診断」への誘導になっているが、リンクの無い4箱では飛び先が存在せず空振りしている。同じ枠を「続きは明日」「他の◯選も出す」に変えたとき、フォロワー転換が動くか。実験1がbioの効果を測るのに対し、これはスライド側の効果を測る。
動かすもの
最終枚のCTA
固定するもの
本文1〜8枚目テイスト箱時刻
手順
育成中の4箱に出す睡眠ノウハウ4本のうち、2本を診断CTAのまま、2本をフォロー誘導に差し替える。本文と枚数は揃え、最終枚だけを入れ替える。同じ箱の中で交互に出すと箱の差が消えるので、1箱につき診断CTA1本・フォロー誘導1本を2日続けて出すのが最も綺麗になる。
判定：実験1と同時に走らせると、bioとCTAのどちらが効いたか分からなくなる。実験1を先に3日回し、その結果が出てから着手する。順番を守ることがこの実験の肝になる。

実験4 — テイスト単体の効果

04 黒基調と古文書を、縦書き・同時刻で正面から比べる 高
何がまだ分かっていないか
8億円の縦書きは黒基調35,200・古文書15,400で2.3倍の差がついたが、箱（integrator / Manuel）と投稿時刻（12:53 / 15:47）も同時に動いている。テイスト別の集計では総合スコアは古文書42.1・黒基調37.1と逆転しており、どちらが強いのか結論が出ていない。
動かすもの
黒基調 / 古文書
固定するもの
本文縦書き枚数投稿時刻（30分以内）
既存データの整理
版箱再生いいね率コメント
黒基調・縦書きintegrator35,2001.89%19
古文書・縦書きManuel15,4001.45%2
とくにコメント19対2という差が大きい。黒基調のほうが議論を起こす力が強い可能性があるが、題材が同じである以上これはテイストか箱のどちらかで説明するしかない。
判定：クロスオーバーで2ラウンド。1回目は黒＝Manuel／古文書＝integrator と今回と逆に割り当てる。それでも黒基調が勝てばテイストの効果、逆なら箱の効果。コメント数も併せて見る。

実験5 — 投稿時間

05 同じ箱・同じ型で、時刻だけをずらす 後回し
なぜ後回しか
現データでは完全に判定不能。12〜15時の6本はすべて7/31の投稿で、経過時間の短さと時刻が分離できていない。ただし効果があったとしても、テイストや縦横ほど大きくない可能性が高く、優先度は下がる。
動かすもの
投稿時刻
固定するもの
箱型（数字型）テイスト枚数
手順
同じ箱に同じ本文は出せないので、同じ型の別本文を使う。Manuelに数字型を4日連続で出し、時刻を 7時 / 12時 / 19時 / 22時 に振る。内容の差がノイズになるため、最低でも2周（8本）は必要になる。判定は24時間後の再生数の中央値。
判定：2周して同じ時間帯が両方とも上位なら採用する。ばらつきが大きく差が2倍未満なら、投稿時刻は運用の都合で決めてよい変数として扱い、それ以上追わない。
