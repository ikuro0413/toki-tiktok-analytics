## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている7本（integrator「8億円」319.9k、neru102「答えようのない質問」209.7k、
  Manuel「8億円」226.4k・「答えようのない質問」144.1k・「AI失業論争」69.5k、
  あんな「8億円」137.3k・「平均という言葉」52.7k、take「297億円」105k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）
- グリッドが読めないときは、いったん上へスクロールしてから下へ戻すと復帰する。
  navigate 直後の待機は8〜9秒必要で、待たずに get_page_text すると「Please wait...」しか返らない
- **未ログインのブラウザでは CAPTCHA（スライダーパズル）が出て取得できない。** ログイン済みの実 Chrome が必須

## 採点基準（事業貢献基準・乗算式／100点）

**総合 ＝ リーチ係数 ×（1再生の価値）**

- リーチ係数: 0〜1.0。再生数の対数スケールで 200再生=0、40,000再生=1.0（天井据え置き）
- 1再生の価値: 次の5項目の合計（0〜100）

| 価値配点 | 項目 | 満点条件・係数 |
|---|---|---|
| 20 | 商材接続 | 題材が商品開発の調査になるか。就寝先延ばし直撃 1.0／睡眠ノウハウ 0.7／睡眠雑学 0.4／時事・論争 0.1 |
| 20 | 導線 | 診断CTAあり 1.0／なし（フォロー誘導含む）0.3 × リンク箱 1.0／育成箱 0.5 |
| 30 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 保存（需要シグナル） | 保存率 0.5% |
| 15 | 会話 | (コメント+シェア)÷再生 が 0.08% |

### 前提

事業の最終目的は「自社製品を作って売る」こと。TikTok・診断・LINE はその手段で、
診断＝どの悩みが多いかの市場調査、フォロワー＝リンク解禁（1,000人）と将来のLINEリスト化の母数、という位置づけ。

**乗算式にした理由**: 加点式では導線や題材の点が再生ゼロでも無条件に乗ってしまう。
導線を入れても、再生されて初めて意味がある。逆に、再生が取りやすくても
診断にもフォロワーにも繋がらない投稿は、1再生の価値が下がる。
設計の点（商材接続・導線）は「見られた量のぶんだけ実現する」形にした。

リンク箱は take と neru102 の2箱のみ。育成箱の導線係数 0.5 は
@メンション・指名検索・フォロー蓄積という迂回路を織り込んだ値で、
**育成箱が再生とフォロワーを追う戦略自体は正しいまま**（リーチ係数とフォロー30で測る）。
商材接続と導線は題材とCTA実態で決まる静的な列なので、再集計時は前回値を引き継ぐ。
変更履歴: 育成基準（リーチ40主軸）→ 事業貢献基準・加点式 → 乗算式（現行）。

   M2 21.8・N1 18.9。**1再生の価値が2倍以上違う**

4. **1再生の価値の首位は T10「布団で目が冴える」の70.0**（商材20＋導線20＋フォロー30満点）。
   まだ306再生。**この投稿に配信が付くかが乗算式が示す最初の実験**

   ノウハウは価値で稼ぐ（44.9）。やることは「ノウハウにリーチを付ける」の一択
6. **take が「価値の箱」になった。** 価値上位4本（T10 70.0・T6 52.2・T9 51.7・T2 47.0）を独占。
   ただしリーチ係数0.1〜0.3で、配信が出ない問題は未解決のまま

   回答ログが今週動くかが最初の答え合わせ
