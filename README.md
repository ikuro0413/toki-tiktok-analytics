# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている7本（integrator「8億円」274.9k、neru102「答えようのない質問」187.9k、
  Manuel「8億円」181.9k・「答えようのない質問」134.8k・「AI失業論争」43.3k、
  あんな「8億円」118.7k、take「297億円」81.5k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（512人）と neru102（327人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **総再生が初めて100万を超えた。** ただし増分の90%（72,900／80,886）は6桁到達組の7本で、
   8/2の新規6本の増分は合計7,070。**成長はまだ既存のバズが牽引している**
2. **「睡眠学は配信が出ない箱」は撤回。** 8/2の「ら抜き言葉」が 717→4,109（5.7倍）まで伸び、
   **既存6本の合計（5,785）を1本で超えた**。止まっていたのは古い投稿であって箱ではない
3. **take だけが立ち上がらない。** 8/2に6箱すべてへ投稿した結果、26時間後は
   睡眠学4,109／neru102 1,235／あんな1,155／Manuel 831／integrator 718 に対し **take だけ244**。
   反応は全項目ゼロ。8/1も1,410で全ゼロ。297億円の8万を除くと総再生は5,050しかない
4. **縦横の差は2.32倍で完全に固定。** 8億円は縦274,900 対 横118,700（経過60.4h対60.5h）。
   7回の測定で 3.3→2.4→2.3→2.40→2.33→2.30→2.32 と収束した
5. **AI失業論争の30.7倍は縦書きの効果ではない。** Manuel縦43,300 対 take横1,410 だが、
   縦横・枚数（22枚対18枚）・箱の3つが同時に動いている。**切り分けは同じ箱の中で縦・横・縦・横**
6. **兆円・万トン単位の題材は自分ごとにならない。** あんな「混ませているのは誰か」（8.1兆円対25.2兆円）と
   take「捨てているのは誰か」（461万トン）は、どちらも26時間で反応が全項目ゼロ
7. **24枚でも離脱していない。** integrator「鵜飼は必要か」は最長24枚で 25→718（28.7倍）、
   **42本中最大の順位上昇（41位→19位）**。会話率は満点
8. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
