# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている6本（integrator「8億円」163.4k、Manuel「8億円」110.9k・「答えようのない質問」94k、
  neru102「答えようのない質問」100.2k、あんな「8億円」71.3k、take「297億円」36.6k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**。前回これを揃えずに比べて縦横の読みを誤った
- **Manuel「17時間の壁」と「14日の実験」は前回の割り当てが入れ替わっていた。**
  投稿IDから復元した時刻とプロフィールグリッドの並び（最新順）で確認して今回訂正した。
  正しくは 17時間の壁 = 7/29 19:37、14日の実験 = 7/29 15:15

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（508人）と neru102（281人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **bio を書き換えた箱で転換率が上がった。** Manuel 0.034%→0.056%（1.66倍）、
   neru102 0.020%→0.032%（1.63倍）。integrator は0.023%→0.026%で微増、あんなは横ばい。
   bio を変えていない take（0.006%）と睡眠学（増分ゼロ）は動いていない。
   ただしbio更新の正確な時刻が不明で、同時に新規投稿の配信も進んでいるため単独の効果とは断定できない
2. **改善した bio は「何が届くか」が具体的だった（仮説）。** 伸びた2箱は
   「知ってるつもりだった話が、数字ひとつでひっくり返る」「言いたいけど言えないこと、代わりに言ってます」。
   横ばいのあんなは「へえ、で終わらせるにはもったいない話」で、何の箱か分かりにくい
3. **縦書きの差がまた開いた。** 「答えようのない質問」は縦162,700 対 横124,600 で1.31倍
   （前回は1.02倍でほぼ同着）。8億円は縦229,300 対 横95,600 で2.40倍で、5回の測定を通じて
   3.3→2.4→2.3→2.40 と**もう縮まっていない**。横書きを選ぶ理由はもう無い
4. **時事なのに保存される型が出た。** Manuel「消えた職業」は24,500再生で保存率0.412%（36本中2位）・
   会話率満点・いいね率0.94%と4項目すべて上位。前回11位から3位へ、36本で最大の上昇。
   時事は再生を取るが保存されない、という分業がこの1本で崩れている
5. **1本に前例は1つまで。** 前例1つの Manuel「消えた職業」は24,500再生・保存率0.412%。
   前例2つの take「AI失業論争」は1,329再生で**いいね/保存/コメントすべてゼロ**。
   27時間経ってこうなので、題材ではなく構成の問題で確定
6. **睡眠学は反応が2位なのにフォロワーが1人。** 新規「夢を忘れる理由」はいいね率1.91%で36本中2位、
   箱平均も6箱中2位。それでもフォロワーは1人のまま。**6箱で唯一 bio が未記入**で、
   プロフィールに来ても何の箱か分からず帰っている可能性が高い
7. **コメントは構成で決まる。** 合計327件のうち 8億円黒縦書き129件・8億円黒横47件・質問古文書46件で67%。
   take「297億円」は51,700再生で16件。読者が言い返せる余地を残した構成だけが会話を生む
8. **6箱合計では1,000人を超えた（968→1,065）が、リンク解禁はアカウント単位なので意味はない。**
   最短は take の510人だが転換率0.006%で動いていない。実質的に近いのは neru102（318人・0.032%）、
   次が Manuel（130人・0.056%）で、転換率が高いのは後者なので逆転しうる
9. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
