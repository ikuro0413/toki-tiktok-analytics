# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## ★訂正（2026-08-02 20:30）

**前回まで Manuel の8/1投稿を「消えた職業」としていたのは誤り。**
実際に投稿されていたのは **「AI失業論争（前例が二度・縦書き古文書22枚）」** で、
take の8/1投稿と **本文が同一** だった（take は同内容の古文書・横書き18枚）。
「消えた職業」は制作しただけで、どの箱にも投稿されていない。

これに伴い、**「1本に前例は1つまで」という結論は撤回する。**
前例を二度立てた本文は Manuel で 34,700再生・保存率0.392%（42本中3位）・会話率満点＝総合2位を取っている。
take で全ゼロだったのは前例の数では説明できない。実際に動いていた変数は **縦横・枚数・箱** の3つ。

原因は、制作フォルダの `caption.txt` に書いた **「推奨箱」を投稿実績として扱ったこと**。
投稿先は制作側では決まらないので、推奨と実績は一致しない。
**以後、タイトルの割り当ては投稿キャプションの本文を制作物と突き合わせて確定する。**
サムネの見た目だけでは、同一本文の版違いを取り違える。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている7本（integrator「8億円」254.5k、neru102「答えようのない質問」176.3k、
  Manuel「8億円」171.4k・「答えようのない質問」130.7k・「AI失業論争」34.7k、
  あんな「8億円」110.8k、take「297億円」71.7k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（512人）と neru102（320人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **「1本に前例は1つまで」は撤回。** 取り違えの上に立っていた結論だった。前例二度立ての本文は
   Manuel で 34,700再生・保存率0.392%（42本中3位）・総合2位。前例の数は説明変数ではない
2. **同じ本文・同じ古文書テイストで、縦横と箱だけが違って24.8倍の差。**
   Manuel 縦書き22枚 34,700 対 take 横書き18枚 1,402。ただし箱の地力差
   （再生中央値 Manuel 6,294 対 take 715）が交絡していて、縦書きだけの効果とは言い切れない
3. **縦横の差は2.30倍で固定した。** 8億円は縦254,500 対 横110,800。7回の測定を通じて
   3.3→2.4→2.3→2.40→2.33→2.30 と収束（経過時間はほぼ同一）。答えようのない質問も1.35倍で固定
4. **睡眠学の判定は保留に戻す。** 既存6本は2.3時間で+1再生と完全停止だが、8/2の新規「ら抜き言葉」は
   数時間で717を出した。**止まっているのは古い投稿であって、箱そのものではない**可能性がある
5. **bio では配信は増えない。** 睡眠学の既存6本の増分は+1再生。
   **bio は来た人を取りこぼさないための施策であって、人を呼ぶ施策ではない**
6. **コメントは構成で決まる。** 合計378件のうち 8億円黒縦書き140件・質問古文書横52件・8億円黒横51件で64%。
   take「297億円」は71,700再生で23件、integrator「リーガルハイ」は3,991再生で0件
7. **ジャンル別の「社会・時事」36.5 は見かけの低下。** 経過数時間の8/2投稿5本が母数に入っただけ。
   次回からジャンル別集計は経過24時間以上に限る
8. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
