# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている6本（integrator「8億円」163.4k、Manuel「8億円」110.9k・「答えようのない質問」94k、
  neru102「答えようのない質問」100.2k、あんな「8億円」71.3k、take「297億円」36.6k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**。前回これを揃えずに比べて縦横の読みを誤った
- **Manuel「17時間の壁」と「14日の実験」は前回の割り当てが入れ替わっていた。**
  投稿IDから復元した時刻とプロフィールグリッドの並び（最新順）で確認して今回訂正した。
  正しくは 17時間の壁 = 7/29 19:37、14日の実験 = 7/29 15:15

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（508人）と neru102（281人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **縦書きが横書きを上回ることで決着した。** 「答えようのない質問」は縦 100,200 対 横 94,000 で
   **ついに逆転**（しかも縦のほうが投稿が3.4時間遅い）。8億円は縦 163,400 対 横 71,300 で2.3倍
   （経過は31.5h対31.6hでほぼ同一）。**前回「横が1.9倍勝ち」と読んだのは、経過時間を揃えずに
   比べた誤り**だった。縦横は縦有利で一貫する
2. **横書きは「立ち上がりが遅い」のではなく最後まで遅い。** 差は 3.3倍→2.4倍→2.3倍 と縮むが、
   4回の測定で一度も逆転していない。縮小を「いずれ追いつく」と読むのは楽観が過ぎる
3. **伸びるのは社会・時事だけ。4回連続で確定。** 既存30本の増分 258,893 のうち 258,341（99.8%）が
   時事6本。残り24本の増分は合計 552。睡眠学の既存5本は11時間で +16 しか動いていない
4. **フォロワーが加速している。** 6箱計 891→968（+77）。Manuel 44→77、integrator 18→36 で
   どちらも11時間で倍近い。1日前は8時間で+34だったのでペースが上がっている。
   転換率は0.02〜0.03%と低いが、**再生を積めばフォロワーは増えるという経路自体は証明された**
5. **睡眠学の問題は内容ではなく配信。** 新規「夢を忘れる理由」はいいね率 2.44% で36本の最高値、
   保存率0.457%も上位。それでも657再生しか出ていない。良い題材を置き続けても回収できない箱
6. **1本に前例は1つまで。** 同じAI失業の題材で、前例1つの Manuel「消えた職業」は3,586再生・
   会話率満点。前例2つの take「AI失業論争」は497再生で**いいね/保存/コメントすべてゼロ**。
   情報量を足すほど反応が消える
7. **コメントは構成で決まる。** 合計231件のうち 8億円黒縦書き105件と答えようのない質問古文書39件で62%。
   take「297億円」は36,600再生でわずか5件。読者が言い返せる余地を残した構成だけが会話を生む
8. **62万再生のうち、行き先があるのは23%。** リンクを持つ take と neru102 の合計は141,756再生。
   残り77%は行き先を持たないままリーチだけを消費している
9. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
