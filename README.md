# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用48投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている7本（integrator「8億円」319.9k、neru102「答えようのない質問」209.7k、
  Manuel「8億円」226.4k・「答えようのない質問」144.1k・「AI失業論争」69.5k、
  あんな「8億円」137.3k・「平均という言葉」52.7k、take「297億円」105k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）
- グリッドが読めないときは、いったん上へスクロールしてから下へ戻すと復帰する。
  navigate 直後の待機は8〜9秒必要で、待たずに get_page_text すると「Please wait...」しか返らない
- **未ログインのブラウザでは CAPTCHA（スライダーパズル）が出て取得できない。** ログイン済みの実 Chrome が必須

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（515人）と neru102（330人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **リーチ40点は約4万再生で天井を打つ。** I1 は301,700再生、M7 は65,600再生だが、リーチ点はどちらも40.0。
   再生を10倍積んでも総合は1点も動かない。**勝負は残りの60点**で、M6 は3,468再生（首位の86分の1）でも総合66.5の4位に入っている
2. **縦横の差は2.35倍で確定。** 同一本文の8億円で 黒縦301,700 対 黒横128,300（投稿時刻は7分差）。
   6回の測定で 3.3→2.4→2.3→2.40→2.33→2.35 と収束し、一度も逆転していない。これ以上測る必要はない
3. **会話15点の取りこぼしが最大の損失。** 0.08% という低い閾値なのに、**48本中16本が会話率ゼロ**。
   締めを問いにしていないだけで15点を捨てている。最高は neru102「AI絵論争」の0.870%
4. **診断適性10.0に初到達（take「寝ないという行動」）。** 睡眠ノウハウ×CTA有の組み合わせを初めて出した。
   ただし449再生・総合26.2の32位で、**診断10点を満額取ってもリーチが出なければ順位には出ない**
5. **睡眠学は「配信が出ない箱」ではなかった。** 「ら抜き言葉」が18時間で +2,708 とまだ伸びている。
   前回までの判定を撤回する。止まっていたのは古い投稿のほう
6. **同じ制作バッチでも箱と題材で桁が変わる。** 8/3投稿の あんな「平均という言葉」17,300 対
   integrator「四パーセントの根拠」925 で **19倍の差**。給特法は制度説明に寄りすぎて読者の生活に接続しなかった
7. **take の不振は3本連続。** 「AI失業論争」「捨てているのは誰か」「江戸の睡眠」がいずれも
   いいね・保存・会話すべてゼロ。bio は直したので、テイストではなく箱の配信の問題として扱う段階
8. **ジャンル別で睡眠ノウハウが首位に立った**（44.6 対 社会・時事43.7）。
   ただし再生中央値は 2,194 対 6,986 で時事が3.2倍。**バズるのは時事、点が取れるのはノウハウ**の分業は不変

## 次に確かめること

- **締めの問いを制作の必須チェックに入れる**。会話率ゼロの16本は0.08%すら踏んでいない
- **診断の到達実数を確認する**。スコアは自作の指標なので、回答ログの本番回答数が動いたかで検証する
- **take で確実に反応の出る型（手順もの）を1本**出し、全ゼロが箱の問題か題材の問題かを切り分ける
- **Manuel の中で睡眠ノウハウを縦・横・縦・横と4本**出して、縦横だけを切り分ける
- **制度ものは早い段階で読者の生活に接続する枚を入れる**（給特法の失敗を型に反映）
