TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用94投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている投稿（integrator「8億円」489.4k、neru102「答えようのない質問」212k・「子を生まない選択」27.9k、
  Manuel「8億円」307.3k・「答えようのない質問」145.1k・「子を生まない選択」167.8k・「AI失業論争」102.7k・「老害」91.4k・「専業主婦」75.5k・「二つのAIの議論」29k・「リモートワーク」20.3k、
  あんな「8億円」143.1k・「平均という言葉」82.3k、take「297億円」108.8k、二つのAI「老害」37.6k・「ら抜き言葉」12.9k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）
- グリッドが読めないときは、いったん上へスクロールしてから下へ戻すと復帰する。
  navigate 直後の待機は8〜9秒必要で、待たずに get_page_text すると「Please wait...」しか返らない
- **未ログインのブラウザでは CAPTCHA（スライダーパズル）が出て取得できない。** ログイン済みの実 Chrome が必須

## 採点基準（事業貢献基準・乗算式／100点）

**総合 ＝ リーチ係数 ×（1再生の価値）**

- リーチ係数: 0〜1.0。再生数の対数スケールで 200再生=0、40,000再生=1.0（天井据え置き）
- 1再生の価値: 次の5項目の合計（0〜100）

| 価値配点 | 項目 | 満点条件・係数 |
|---|---|---|
| 20 | 商材接続 | 題材が商品開発の調査になるか。就寝先延ばし直撃 1.0／睡眠ノウハウ 0.7／睡眠雑学 0.4／時事・論争 0.1 |
| 20 | 導線 | 診断CTAあり 1.0／なし（フォロー誘導含む）0.3 × リンク箱 1.0／育成箱 0.5 |
| 30 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 保存（需要シグナル） | 保存率 0.5% |
| 15 | 会話 | (コメント+シェア)÷再生 が 0.08% |

### 前提

事業の最終目的は「自社製品を作って売る」こと。TikTok・診断・LINE はその手段で、
診断＝どの悩みが多いかの市場調査、フォロワー＝リンク解禁（1,000人）と将来のLINEリスト化の母数、という位置づけ。

**乗算式にした理由**: 加点式では導線や題材の点が再生ゼロでも無条件に乗ってしまう。
導線を入れても、再生されて初めて意味がある。逆に、再生が取りやすくても
診断にもフォロワーにも繋がらない投稿は、1再生の価値が下がる。
設計の点（商材接続・導線）は「見られた量のぶんだけ実現する」形にした。

リンク箱は take と neru102 の2箱のみ。育成箱の導線係数 0.5 は
@メンション・指名検索・フォロー蓄積という迂回路を織り込んだ値で、
**育成箱が再生とフォロワーを追う戦略自体は正しいまま**（リーチ係数とフォロー30で測る）。
商材接続と導線は題材とCTA実態で決まる静的な列なので、再集計時は前回値を引き継ぐ。
変更履歴: 育成基準（リーチ40主軸）→ 事業貢献基準・加点式 → 乗算式（現行）。

## 主な結論（28回目）

1. **★「良い弾は消耗品ではない」。** M1の再燃が3回連続（+13,400→+20,900→+16,300）で確定し307,300に到達。
   **箱が伸びる時期には旧弾にも配信が回り直す**ので、質の高い弾を積んでおくこと自体に複利がある
2. **観戦型の寿命は5日以上。** M16は5日目でも日次+11,800、M15も+7,900。M11以来の水準で、
   **観戦型は「2〜3日で跳ねて終わり」ではなく1週間かけて積み上がる**
3. **議題の当たり外れは観戦型の中でも7倍。** M17飲み会は2日目6,125で、同時点のM16（41,000）の1/7。
   同じ型・同じ箱でも**当事者性が家族・世代に一段劣る議題は伸びしろが小さい**
4. **Manuel1箱に勢いが集中。** 24時間の増分43,789のうち**Manuelが38,995（89%）**。箱再生97.1万＝全体の45%。
   フォロワーも24時間で+37人＝このペースなら8〜9日でリンク解禁（残り310人）
5. **二つのAIとManuelで「バズ中の新弾」の挙動が逆。** M17は谷に落ちないが、S15・S14は2本続けて谷から出ない。
   **「別議題ならバズ中でも投入可」はManuelの箱力があってこそ**と読み直すべき
