# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用48投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている7本（integrator「8億円」319.9k、neru102「答えようのない質問」209.7k、
  Manuel「8億円」226.4k・「答えようのない質問」144.1k・「AI失業論争」69.5k、
  あんな「8億円」137.3k・「平均という言葉」52.7k、take「297億円」105k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）
- グリッドが読めないときは、いったん上へスクロールしてから下へ戻すと復帰する。
  navigate 直後の待機は8〜9秒必要で、待たずに get_page_text すると「Please wait...」しか返らない
- **未ログインのブラウザでは CAPTCHA（スライダーパズル）が出て取得できない。** ログイン済みの実 Chrome が必須

## 採点基準（事業貢献基準／100点）

| 配点 | 項目 | 満点条件・係数 |
|---|---|---|
| 20 | 商材接続 | 題材が商品開発の調査になるか。就寝先延ばし直撃 1.0／睡眠ノウハウ 0.7／睡眠雑学 0.4／時事・論争 0.1 |
| 20 | 導線 | 診断CTAあり 1.0／なし（フォロー誘導含む）0.3 × リンク箱 1.0／育成箱 0.5 |
| 20 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 保存（需要シグナル） | 保存率 0.5% |
| 15 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 10 | 会話 | (コメント+シェア)÷再生 が 0.08% |

### 前提

事業の最終目的は「自社製品を作って売る」こと。TikTok・診断・LINE はその手段で、
診断＝どの悩みが多いかの市場調査、フォロワー＝リンク解禁（1,000人）と将来のLINEリスト化の母数、という位置づけ。
旧・育成基準（リーチ40／フォロー25／会話15／保存10／診断適性10）はアカウント育成局面の物差しで、
事業への接続を10点しか見ていなかったため、この版で廃止した。

リンク箱は take と neru102 の2箱のみ。育成箱の導線係数 0.5 は
@メンション・指名検索・フォロー蓄積という迂回路を織り込んだ値で、
**育成箱が再生とフォロワーを追う戦略自体は正しいまま**（リーチ15＋フォロー20で測る）。
商材接続と導線は題材とCTA実態で決まる静的な列なので、再集計時は前回値を引き継ぐ。

## 主な結論

1. **首位は3,510再生の Manuel「10-3-2-1-0」（60.5）。** 319,900再生の integrator「8億円」は6位、
   69,500再生の Manuel「AI失業論争」は2位。**再生の桁は順位を決めない**配点になった
2. **take「寝ないという行動」が33位→3位。** 就寝先延ばし直撃×診断CTA×リンク箱で
   商材接続20＋導線20を両取りできる設計は **48本中この1本だけ**。量産すべき型がこれ
3. **時事は中位へ下がったが、役割は消えていない。** リーチとフォロワーの調達係に限定されただけで、
   時事で人を集めてノウハウ×CTAで診断へ送る分業は新基準でも変わらない
4. **ジャンル差が開いた**: 睡眠ノウハウ43.5 ≫ 社会・時事29.4（旧基準では44.6対43.7でほぼ同点）。
   制作リソースの配分根拠がはっきりした
5. **neru102 の矛盾が数字になった。** リンクがある箱なのに診断CTA付き投稿がゼロ。
   導線満点を取れる2箱のうち1箱が遊んでいる
6. **縦横の差は2.35倍で確定**（据え置き）。6回の測定で一度も逆転していない。これ以上測る必要はない
7. **take の不振は3本連続**（据え置き）。全ゼロ3本は箱の配信の問題として扱う段階
8. **導線20点はまだ設計値。** 診断の本番回答はゼロのまま。bio の短縮URLは差し替え済みなので、
   次の答え合わせは回答ログの本番回答数が動くかどうか
