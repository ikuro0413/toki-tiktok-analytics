# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている6本（integrator「8億円」283.5k、neru102「答えようのない質問」194.2k、
  Manuel「8億円」192.2k・「答えようのない質問」137.1k・「AI失業論争」50.3k、
  あんな「8億円」120.9k、take「297億円」89.7k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **版違いの比較には必ず経過時間を併記する**
- **タイトルの割り当てはキャプション本文の照合で確定する**（サムネと投稿ID時刻は補助）
- **★グリッドが「不明なエラー」で止まったら、エラーカード内の「更新」ボタンをクリックする。**
  今回4箱で発生し、4箱とも更新ボタンで復帰した。上下スクロールより確実で速い

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（513人）と neru102（327人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **この頻度で測る意味はもう無い。** 既存42本のうち **35本が順位を1つも動かさなかった**。
   動いた7本も最大±3。**投稿48時間でスコアが固まる**という読みが決定的になった。
   次に測る価値があるのは、8/3の3本が24時間経ったとき
2. **縦横の差は2.35倍で固定。** 8億円は縦283,500 対 横120,900（経過73.4h対73.5h）。
   8回の測定で 3.3→2.4→2.3→2.40→2.33→2.30→2.32→2.35。これ以上測っても変わらない
3. **睡眠学は1本だけまだ伸び続けている。** 「ら抜き言葉」は4,109→4,569（+460）で
   既存6本の合計（5,793）にほぼ並んだ。一方 **既存6本の13時間の増分は合計+8**
4. **兆円・万トンの2本は39時間経っても反応が全項目ゼロ。**
   あんな「混ませているのは誰か」（8.1兆円対25.2兆円）と take「捨てているのは誰か」（461万トン）。
   単位が大きすぎると読者の生活に接続しない
5. **箱スコアは新規投稿を混ぜると壊れる。** 0再生の8/3投稿を含めると Manuel 55.1→49.2、
   integrator 34.8→30.6 と落ちるが、これは見かけ。**経過24時間未満は分離して計算する**
6. **take は8億円級を1本も再現できていない。** 297億円（89,700）を除くと総再生は5,157。
   8/1・8/2の投稿はどちらも反応が全項目ゼロ。**6箱で唯一 bio が未変更**
7. **フォロワーが増えたのは Manuel だけ**（+10・転換率0.050%）。6箱計+13は前回の+33から半減
