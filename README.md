# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、投稿時間・テイスト・枚数・文字量・内容の相関分析 |

どちらも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## データの前提

- 集計基準日: 2026-07-31 21:10 JST のスナップショット
- 対象: 新運用（2026-07-28 以降）の投稿のみ。旧 #pr 投稿は除外
- 対象アカウント: take / Manuel / integrator / あんな / 睡眠学 / neru102 の6箱
- 総再生 100,929 / 30本

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- integrator「8億円」(`35.2k`) と Manuel「8億円」(`15.4k`) は TikTok の表示が丸めのため、
  エンゲージ率から逆算した値を採用

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（508人）と neru102（280人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **再生がフォロワーに変わっていない。** 総再生 100,929 に対し、この4日で増えたフォロワーは
   6箱合計で13人程度（Manuel 7→12、integrator 1→6、あんな 32→33、睡眠学 1のまま）。
   リンク解禁の条件がフォロワー数である以上、ここが本当のボトルネック
2. **bio に「フォローする理由」が書かれていない。** Manuel「tiktokやめたい」、
   integrator「tiktok見るのやめよ」、あんな・睡眠学は未記入。
   リンクは置けなくても文章は今すぐ置ける
3. **縦書きが横書きの16倍の再生を取る。** 縦書き3本の再生中央値15,400に対し横書き27本は956。
   同一本文・同一テイスト・ほぼ同じ経過時間の8億円で比較しても、縦書き35,200 対 横書き5,404 で6.5倍
4. **バズ題材と送客題材が逆の箱に入っている。** リンクの無い Manuel に保存率最高のノウハウ（0.408%）、
   あんなに寝る前NG5選（0.305%）
5. 睡眠ノウハウはジャンル別で総合 51.5 のトップ。いいね率・保存率とも社会・時事を上回る
6. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解
7. 枚数と再生の相関 r=0.66 は見せかけ。時事6本を除くと r=0.01 に消える
8. 初速のいいね率は当てにならない。takeの297億円は投稿1時間で2.40%（30本中最高）だったが、
   3,785再生まで伸びた時点で0.79%に落ちた。最低1,000再生を超えてから判断する
9. 投稿時間の効果は、投稿が 7/31 に集中していて経過時間と交絡しているため **現データでは判定不能**
