# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、投稿時間・テイスト・枚数・文字量・内容の相関分析 |

どちらも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## データの前提

- 集計基準日: 2026-07-31 19:40 JST のスナップショット
- 対象: 新運用（2026-07-28 以降）の投稿のみ。旧 #pr 投稿は除外
- 対象アカウント: take / Manuel / integrator / あんな / 睡眠学 / neru102 の6箱
- 総再生 67,377 / 30本

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- integrator「8億円」の再生数のみ TikTok の表示が `13.7k` 丸めのため、エンゲージ率から逆算した 13,700 を採用

## 採点基準（100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 30 | リーチ | 再生数の対数スケール。200再生=0点、15,000再生=満点 |
| 25 | エンゲージ質 | エンゲージ率 2.5% |
| 15 | 保存 | 保存率 0.5% |
| 10 | 会話喚起 | (コメント+シェア)÷再生 が 0.08% |
| 20 | 診断誘導の実効性 | bioリンク有無 × 内容の動機づけ × スライド末尾CTA の積 |

診断誘導は「プロフィールにリンクが無い箱は遷移先が存在しないので0点」という前提で計算している。
リーチ4項目だけを100換算した **バズ力** も併記してあるので、送客を外して純粋な伸びだけ見ることもできる。

## 主な結論

1. 総再生の **82%（55,227）** が、bio にリンクの無い4箱で発生していて行き先を持たない
2. 保存率は睡眠ノウハウ 0.213% に対し社会・時事 0.122%。**バズるのは時事、連れて行けるのはノウハウ**
3. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解
4. 枚数と再生の相関 r=0.59 は見せかけ。時事6本を除くと r=0.02 に消える
5. 投稿時間の効果は、投稿が 7/31 に集中していて経過時間と交絡しているため **現データでは判定不能**
