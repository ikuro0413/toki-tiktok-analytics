# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

- 対象: 新運用（2026-07-28 以降）の投稿のみ。旧 #pr 投稿は除外
- 対象アカウント: take / Manuel / integrator / あんな / 睡眠学 / neru102 の6箱
- 総再生 207,068 / 30本（前回 100,929 / 30本。新規投稿はなく再生だけが 2.05 倍になった）

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている5本（integrator「8億円」82k、Manuel「8億円」25.7k・「答えようのない質問」28.7k、
  あんな「8億円」17.6k、neru102「答えようのない質問」11.1k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **Manuel「17時間の壁」と「14日の実験」は前回の割り当てが入れ替わっていた。**
  投稿IDから復元した時刻とプロフィールグリッドの並び（最新順）で確認して今回訂正した。
  正しくは 17時間の壁 = 7/29 19:37、14日の実験 = 7/29 15:15

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（508人）と neru102（281人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **伸び続けるのは社会・時事だけ。** 3.5時間の増分 106,139 のうち 105,360（99.3%）が時事6本。
   残り24本の増分は合計 779 しかない。**睡眠ノウハウ・雑学・論争は投稿翌日には配信が止まり、
   時事だけが半日〜1日かけて指数的に伸びる**。同じ時点で比べると必ず時事が過大評価される
2. **「縦書きが16倍」は撤回。** 「答えようのない質問」は横書き（Manuel 28,700）が
   縦書き（neru102 11,100）を 2.6 倍上回った。8億円では逆に縦書きが勝っている。
   **縦横の効果は箱と題材から分離できていない**というのが現状の正確な認識
3. **前回の保留が正しかった。** Manuel「答えようのない質問」は 1,782 → 28,700（16倍）で
   24位から6位へ。**投稿12時間以内の数字で型の良否を決めてはいけない**。
   判定は投稿翌日の同時刻に揃える
4. **伸びた投稿の反応率は必ず下がる。** あんな「8億円」いいね率 0.67%→0.36%、
   integrator「8億円」1.89%→1.62%。再生規模の違う投稿どうしで反応率を比べてはいけない
5. **総合トップが睡眠ノウハウから社会・時事へ入れ替わった**（53.9 対 51.5）。
   ただし逆転の中身はリーチ点だけで、いいね率・保存率はノウハウが勝ち続けている。
   バズるのは時事、連れて行けるのはノウハウという分業は動いていない
6. **コメントは黒基調に集まる。** 合計90件のうち integrator「8億円（黒縦書き）」55件と
   Manuel「答えようのない質問（古文書）」14件で77%。
   数字提示で終わった take「297億円」は 9,999再生でコメント・シェアともゼロ
7. **再生はフォロワーに変わり始めたが、量が足りない。** 3.5時間で +17人
   （Manuel +10 / integrator +6 / neru102 +1）＝転換率 0.016%。
   新運用開始からの累計でも育成4箱で +30人程度で、リンク解禁の1,000人には遠い
8. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
9. バズ題材と送客題材が逆の箱に入っている。リンクの無い Manuel に保存率トップの 10-3-2-1-0、
   あんなに寝る前NG5選（変わらず）
