# toki-tiktok-analytics

TOKI ブランドの TikTok 運用（6箱体制）の分析資料を置くリポジトリ。
中身は社内向けの運用データなので **private** にしてある。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | マーケティング導線マップ。TikTok 6箱 → プロフィールリンク → 睡眠力診断 までの経路と、断線している箇所 |
| `scorecard.html` | 投稿スコアカード。新運用30投稿の全数採点と、1本ずつの講評、テイスト・ジャンル・版違いの集計 |
| `experiments.html` | 検証パターン。まだ分離できていない変数を1つずつ潰すための5つの実験と7日間の回し方 |

どれも単体で開ける HTML で、外部リソースへの依存はない。ライト／ダーク両対応。

## 数値の取得方法

- 再生・いいね・保存・コメント・シェアは各アカウントの公開プロフィールから取得
- エンゲージ率 = (いいね + 保存 + コメント + シェア) ÷ 再生
- **投稿時刻は TikTok の投稿IDから復元した実測値**。ID の上位32bitが UNIX 秒になっている

  ```js
  new Date(Number(BigInt(postId) >> 32n) * 1000)
  ```

- 表示が丸められている6本（integrator「8億円」116.3k、Manuel「答えようのない質問」64.4k・「8億円」52k、
  あんな「8億円」35.4k、neru102「答えようのない質問」34.4k、take「297億円」15.7k）は、
  表示されているエンゲージ率と整合する範囲に収まることを確認した上で丸め値を採用
- **Manuel「17時間の壁」と「14日の実験」は前回の割り当てが入れ替わっていた。**
  投稿IDから復元した時刻とプロフィールグリッドの並び（最新順）で確認して今回訂正した。
  正しくは 17時間の壁 = 7/29 19:37、14日の実験 = 7/29 15:15

## 採点基準（育成基準／100点）

| 配点 | 項目 | 満点条件 |
|---|---|---|
| 40 | リーチ | 再生数の対数スケール。200再生=0点、40,000再生=満点 |
| 25 | フォロー転換力 | いいね率（いいね÷再生）2.2% |
| 15 | 配信継続力 | (コメント+シェア)÷再生 が 0.08% |
| 10 | 保存 | 保存率 0.5% |
| 10 | 診断適性 | 内容の動機づけ × スライド末尾CTA（**リンク有無は掛けない**） |

### 前提

TikTok のプロフィールにリンクを置くにはフォロワー数の条件がある。
take（508人）と neru102（281人）は中古アカウントを転用した際に既に枠を持っていた箱で、
残り4箱は条件に届いていない。つまり **リンクが無いのは設定漏れではなく段階の問題** で、
その4箱が再生数を追うのは正しい戦略になる。
そのため配点はリンクの有無を掛けず、リーチとフォロー転換力を主軸に据えている。

## 主な結論

1. **伸びるのは社会・時事だけ。3回連続で確定。** 8時間の増分 143,479 のうち 143,101（99.7%）が
   時事6本。**残り24本の増分は合計 378**で、5本まとめて増分30しかない箱もある。
   睡眠ノウハウ・雑学・論争は投稿翌日には配信が完全に終わり、時事だけが2日目も伸び続ける
2. **再生がフォロワーに変わりはじめた。** 6箱計 857→891（+34）。うち Manuel が 22→44 で倍増、
   integrator が 12→18。**増えたのはバズった2箱だけ**で、他4箱はほぼ動いていない。
   転換率は Manuel 0.033%・integrator 0.015%。1,000人に届く経路が初めて数字として見えた
3. **スコアが収束した。** 30本中23本が順位を1つも動かさなかった（動いた7本も最大4つ）。
   前回は18位動いた投稿があった。**投稿から20時間を過ぎると順位はほぼ固まる**ので、
   判定タイミングを「投稿翌日の同時刻」に置く運用が正しいと裏付けられた
4. **縦横は依然として分離できていない。** 8億円は縦書き116,300 対 横書き35,400 で縦の4倍勝ち
   （経過時間20.1h対20.2hでほぼ同一）。一方「答えようのない質問」は横書き64,400 対
   縦書き34,400 で横の1.9倍勝ち。**縦横だけを動かした比較が存在しない**
5. **好かれなくてもフォローはされる。** Manuel「答えようのない質問」はいいね率0.21%で30本最下位
   なのに、この箱のフォロワーは8時間で倍増した。**いいね率をフォロー転換力の代理指標にしている
   前提が、大量リーチの時事では崩れる**可能性がある
6. **コメントは構成で決まる。** 合計126件のうち 8億円黒縦書き76件と答えようのない質問古文書22件で78%。
   take「297億円」は15,700再生でコメントゼロ。読者が言い返せる余地を残した構成だけが会話を生む
7. **35万再生で診断への到達は依然ゼロ。** リンクを持つ take と neru102 の合計は54,310再生＝全体の15%。
   残り85%は行き先を持たないままリーチだけを消費している
8. 白・淡色テイストは4本すべて下位。暗い地＋明朝が正解（変わらず）
9. バズ題材と送客題材が逆の箱に入っている。リンクの無い Manuel に保存率上位の 10-3-2-1-0、
   あんなに寝る前NG5選（変わらず）
